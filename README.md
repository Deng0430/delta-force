## 项目简介

三角洲战术地图将地图信息、阶段据点、载具部署、干员编组和行动路线集中到一个工作台中。它既可以作为浏览器应用运行，也可以打包为 Windows 桌面应用，适合战前规划、队伍分工、战术复盘和自定义模式配置。

项目不依赖后端服务。编辑状态、战术方案和模式配置默认保存在浏览器或 Electron 的本地存储中。

## 0.0.1 更新内容（相较 0.0.0）

### 正式版地图与图层

- 重构“地图道具”和“据点与防线”图层控制，支持总开关的部分选中状态，并允许总项关闭后单独开启子项。
- 将据点显示拆分为据点标识、据点占领区域和据点所在防线三个独立子项。
- 进攻活动区、防守活动区及据点所在防线取消区域填色，仅保留外部框线，减少对底图的遮挡。
- 正式版途经点统一显示为 `1、2、3…` 编号。
- 修复固守兵线箭头、第二种箭头样式及部分箭头与路线错位问题。

### 战术板与 HTML 导出

- 导出的当前阶段战术板包含攻守双方活动区，并与正式版采用一致的区域显示规则。
- 导出各类兵器路线时显示编号途经点，不再额外标记兵线起点和终点。
- 修复导出箭头与直线错位、单兵棋状态点显示异常等问题。
- 完善路线、兵棋、地图元素与阶段数据的独立 HTML 渲染。

### 行动指令与路线

- 压缩“行动指令”面板布局，通过折叠和分组减少侧栏占用。
- 路线初始颜色改为队伍色，更换指令类型时不再自动覆盖线条颜色。
- 将“指令色”调整为通用“线条颜色”，支持手动改色、恢复队伍色以及一键采用指令色。
- 固守与其他指令统一使用真实箭头表达，同时保留明确的指令类型识别。

### 兵棋推演

- 恢复单兵兵棋，并为单兵和载具兵棋统一显示队伍字母。
- 载具兵棋改为等边切角外形，以队伍色作为背景；无队伍属性时使用阵营色。
- 新增建筑单位“碉堡”，支持固定机枪、固定防空炮和岸防炮三种形态。
- 建筑单位采用六边形外形，支持阵营、可选队伍属性及图标旋转。
- 统一步兵、载具和建筑兵棋的阵营外发光规则；载具支持右键直接删除。
- 优化兵棋推演面板及阵营、队伍切换控件布局。

### 地图编辑器

- 新增全屏模式和地图元素显示开关，可分别隐藏区域、复活点、据点和地图道具。
- 精简重复的据点与复活点添加入口，保留自由绘制区域能力。
- 草稿权限的区域、复活点、据点和地图道具支持选中后移动；区域可整体拖动并继续编辑顶点。
- 调整 Leaflet 图层层级，确保复活点、据点和地图道具不会被区域图层遮挡交互。
- 支持 Ctrl/Shift 连续多选、批量复制粘贴和批量删除；粘贴对象保持原坐标，不再自动错位。
- 修复阶段、模式、区域、复活点、据点及备注输入时的字符串抖动问题。
- 支持导入、导出和同步模式地图数据，编辑结果可继续用于正式版。

### 快捷键

- 正式版与编辑器统一支持 `Ctrl+C`、`Ctrl+V`、`Ctrl+Z`、`Ctrl+Y`。
- 支持按住 `Ctrl` 单击增减选，按住 `Shift` 在列表中连续多选。
- 支持使用 `Backspace` 删除当前单选或多选内容；输入框聚焦时保留正常文字编辑行为。
- 正式版和编辑器均新增可随时查看的快捷键帮助列表。

### 胜者为王模式数据

- 内置“攀升·胜者为王”5 个阶段的活动区、防线、据点、复活点、地图道具和载具部署数据。
- 内置“烬区·胜者为王”4 个阶段的活动区、防线、据点、复活点、地图道具和载具部署数据。
- 新安装可直接使用上述数据；已有用户通过模式存储迁移获得新增地图数据，迁移后继续保留后续编辑结果。

### 稳定性与工程维护

- 主地图存档兼容版本扩展至 v16，并在无有效存档时恢复默认干员数据。
- 修正 `@dnd-kit/utilities` 依赖版本声明，使 `package.json`、锁文件和实际依赖树保持一致。
- 完善撤回、恢复、多选状态与编辑器历史记录，减少拖动和文本输入产生的无效历史。

## 核心功能

- 支持 11 张全面战场地图，并按地图展示阶段、据点、攻守方复活点、活动区域和地图道具。
- 在攻方与守方视角之间独立编辑部署，避免双方标注相互干扰。
- 提供自由画笔、直线、箭头、防线、矩形、圆形、文字、套索和橡皮擦等地图工具。
- 支持颜色、粗细、线型、曲线、箭头样式、填充和橡皮擦范围等绘制参数。
- 支持撤回、恢复、选中删除，以及分别清除绘制、载具或全部战术内容。
- 支持地面、空中和水上载具部署，自定义阵营与小队归属。
- 支持攻守双方干员、小队、队标、状态、协同关系和批量部署管理。
- 支持机动、进攻、侦察、迂回、撤退、护送、补给和固守等行动指令。
- 行动路线可绑定小队、单兵或载具，并支持节点编辑、反转、复制和分支路线。
- 战术方案可以保存、重新应用，并导出为可独立打开的 HTML 战术板。
- 内置独立模式配置器，可编辑阶段、区域、据点、复活点、地图道具和载具规则。

## 技术栈

- React 19 + TypeScript
- Vite 8
- Leaflet + React Leaflet
- Leaflet Draw
- Electron 43
- electron-builder + NSIS

## 环境要求

- Node.js 20.19+、22.12+ 或更高版本
- npm 10+
- Windows 安装包构建需要 Windows x64 环境
- 地图瓦片来自在线资源，使用地图时需要网络连接

## 本地开发

安装依赖：

```bash
npm install
```

启动 Web 开发服务器：

```bash
npm run dev
```

浏览器访问：

```text
http://127.0.0.1:5173
```

Windows 用户也可以双击 `start-server.bat` 启动开发服务器。

## Electron 开发

先在一个终端启动 Vite：

```bash
npm run dev
```

再在另一个终端启动 Electron：

```bash
npm run electron:dev
```

开发模式下 Electron 会加载 `http://127.0.0.1:5173`。

## 构建

构建 Web 静态资源：

```bash
npm run build
```

本地预览生产构建：

```bash
npm run preview
```

构建 Windows x64 NSIS 安装包：

```bash
npm run build:win
```

构建产物输出到 `dist/` 和 `release/`。这些目录不纳入版本控制。

## 项目结构

```text
map-tools/
├─ build/                 # 应用 Logo、Windows 图标与 NSIS 安装脚本
├─ electron/              # Electron 主进程与内置静态服务器
├─ public/                # 干员、载具和界面静态资源
├─ src/
│  ├─ components/        # 地图图层、工具栏、推演面板与模式配置器
│  ├─ config/            # 地图、阶段、据点、干员和载具数据
│  ├─ utils/             # 本地存储、数据转换与战术板导出
│  ├─ App.tsx            # 主应用状态与业务编排
│  └─ types.ts           # 核心数据类型
├─ index.html             # 主地图入口
├─ mode-config.html       # 模式配置器入口
├─ electron-builder.yml   # Windows 打包配置
└─ vite.config.ts         # Web 构建配置
```

## 数据存储

- 主地图状态使用 `deltaforce-tactical-map-v1` 存储键。
- 模式配置使用 `deltaforce-mode-configs-v1` 存储键。
- Web 版数据位于浏览器 `localStorage`。
- 桌面版数据位于 Electron 用户数据目录对应的本地存储中。
- 卸载程序默认保留用户数据，重新安装后可以继续使用已有方案。
